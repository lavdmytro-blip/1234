# КИРПИЧ: ПОБЕГ ВДВОЁМ 🧱

Полноценная небольшая **онлайн-игра для двух игроков**, которую можно бесплатно открыть в браузере и развернуть на Railway (в рамках доступных ресурсов аккаунта).

## Как играть

1. Первый игрок нажимает **Создать комнату** и копирует ссылку приглашения.
2. Второй игрок открывает ссылку, указывает имя и нажимает **Войти**.
3. Создатель начинает игру. Надо найти **четыре детали**, убегая от Кирпича.
4. Если Кирпич поймал друга, подойдите к нему и **зажмите E**, чтобы поднять.
5. Когда все детали собраны, **оба игрока** должны стоять у ворот с надписью «ВЫХОД».

Управление на компьютере: **WASD / стрелки** — движение, **Shift** — ускорение, **E** — спасение друга. На телефоне есть сенсорные кнопки.

## Запустить на компьютере

Требуется Node.js 20 или новее.

```bash
npm install
npm start
```

Открыть `http://localhost:3000`. Для проверки онлайн на двух устройствах лучше разместить проект на Railway и открыть его публичную ссылку.

## Развернуть на Railway

**Способ 1: через GitHub**

1. Распакуйте архив. Создайте **пустой репозиторий GitHub** и загрузите туда **всё содержимое** папки `kirpich-duo` (файл `package.json` должен быть в корне репозитория).
2. Railway → **New Project** → **Deploy from GitHub repo** → выберите репозиторий.
3. Railway сам определит Node.js. В проекте есть `railway.json`; команда запуска — `npm start`.
4. В Railway у сервиса откройте **Settings → Networking / Public Networking → Generate Domain**.
5. Откройте адрес `https://...up.railway.app`, создайте комнату и пришлите другу ссылку.

**Способ 2: через Railway CLI (без GitHub)**

В терминале внутри папки проекта:

```bash
npm install -g @railway/cli
railway login
railway init
railway up
```

Затем включите публичный домен для созданного сервиса в Settings → Networking.

### Нужны ли переменные окружения?

**Нет.** Railway задаёт переменную `PORT` автоматически, а сервер использует её сам. Не нужно добавлять токены, базу данных или отдельный URL для WebSocket.

### Важно

- Комнаты и ход игры хранятся **в памяти сервера**; после перезапуска/нового деплоя активные комнаты исчезнут.
- Пока нет базы данных: это небольшая онлайн-игра на **один экземпляр сервера**. В Railway оставьте **1 реплику**, иначе комнаты разных игроков могут попасть на разные экземпляры.
- Кирпич пока изображён как **авторский мультяшный персонаж**. Настоящая фотография или озвучка в архив не включены.
- Музыка и звуки синтезируются внутри браузера; по умолчанию они выключены, включить можно кнопкой `♫ OFF`.

## Структура

```text
kirpich-duo/
├── package.json        # Зависимости и скрипты
├── railway.json        # Конфигурация Railway
├── server.js           # Комнаты, физика, ИИ и онлайн-синхронизация
├── public/
│   ├── index.html      # Все экраны игры
│   ├── styles.css      # Визуальное оформление
│   ├── game.js         # Управление, рендеринг, звуки и UI
│   └── favicon.svg
└── tests/
    ├── static-smoke.js # Проверка правил и карты без сети
    └── smoke.js        # Интеграционный тест после npm install
```

## Проверка

После установки зависимостей:

```bash
npm test
```

Выполняется статическая симуляция сервера и проверка реального подключения двух Socket.IO-клиентов.
